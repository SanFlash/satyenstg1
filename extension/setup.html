01 — INSTALL

Get set up in a few minutes

Follow these steps in order. Chrome requires a restart after native host registration.

1

Download and extract

Download the ZIP above and extract the complete folder. Do not run the installer from inside the ZIP preview.

SatyTracker78-Windows-Setup.zip
2

Run the guided installer

Open the extracted folder and double-click Setup-SatyTracker78.cmd. Windows may ask you to confirm that you want to run a downloaded file.

Setup-SatyTracker78.cmd
3

Register this extension

Copy the extension ID below and paste it into the installer when prompted. This limits the native helper to this exact extension.

Loading extension ID…
4

Restart Chrome and connect

Fully exit Chrome and reopen it. Open the SatyTracker78 popup, then choose Connect & enable desktop helper. Approve the Windows permission dialog only when you are ready to allow desktop input.

✓
Setup complete?

02 — REQUIREMENTS

Before you begin

  • Windows 10 or Windows 11, 64-bit
  • Google Chrome with SatyTracker78 installed
  • Permission to run an app for your Windows user account
  • Internet access to download the setup package

No separate .NET SDK, Python, pip, or administrator access is intended to be required.

03 — CONTROL & PRIVACY

You stay in control.

  • Desktop access starts disabled.
  • A Windows permission dialog asks before control is enabled.
  • Permission expires after five minutes.
  • Stop or closing Chrome revokes permission.
  • No screenshots, clipboard capture, hidden keystroke logging, or idle spoofing.
04 — NEED HELP?

Connection not working?

Check that the extension ID entered during setup matches the ID above. Restart every Chrome window and reconnect.
